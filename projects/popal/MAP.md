# Карта кода «ПОПАЛ» (Remotion)

Сгенерировано `node remotion/scripts/map.mjs`. Читать вместо исходников; в файл лезть только за нужными строками (`grep -n`).

Серия = модуль `src/epN/timeline.mjs` (SPEC планов: id, мин. длительность, реплики, звуки; CAP субтитры; statsAt табло) + планы `src/epN/Shots*.tsx` + `EpN.tsx` (MAP id → компонент) + композиции в `src/Root.tsx`.
Конвейер серии: `vo/epN.json` → `tools/vo-qwen.py` → `scripts/post-vo-ep2.sh` (длительности, слова, рот) → `scripts/export-ep2.mjs` (sfx-epN.json) → `tools/sfx.py` → `public/epN-mix.wav` → `npx remotion render EpN-720` → `tools/master.py`.

Координаты: кадр 1080×1920; фигуры — начало между ступнями; `s=1` ≈ рост 740 px; субтитры y≈1290 → лица выше 1100.
