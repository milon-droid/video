# ЛАВА — план и статус

Без слов (понятно на любом языке; язык проекта — английский: подпись к посту на английском). 49 с, 720×1280, 30 к/с.
Движок: `src/shader.js` (GLSL SDF-рейтрейсер: колба, жидкость, воск с глазами/веками/ртом, комната, рассвет) +
`src/engine.js` (WebGL2, проход сцены → RGBA16F с mip → пост: DOF, bloom, FXAA, ACES) + `src/story.js` (кадры по времени).
Звук: `audio/sound.py` → `audio/mix.wav` (своя музыка лаунж-70-х, плёнка тормозит/разгоняется, CC0-записи из `assets/sfx`).

Рендер: `RS=.75 node render.cjs render/lava_v1.mp4` (RS — доля разрешения прохода сцены; ~1,5 с/кадр при RS .5,
SwiftShader сам многопоточный — WORKERS не ускоряет). Превью: `RS=.5 SCALE=.25 node still.cjs out.png t1 t2 …`.
