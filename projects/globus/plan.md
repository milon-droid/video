# SNOW GLOBE («globus») — план

**Идея:** бытовое + одно допущение: фигурка в снежном шаре живая. Снег в его мире идёт, только когда шар трясут.
Конечная мысль — от предмета истории: **«It never snows in a world nobody picks up.»**
**Стиль (термин):** макросъёмка снежного шара — физическая оптика стекла (преломление по Снеллю, френель,
хроматическая аберрация, полное внутреннее отражение, каустика) + расписная миниатюра из смолы + снег в глицерине
(вязкое падение), внешний мир — боке макрообъектива. Свой движок: WebGL2-шейдер, луч × сфера, слои-плоскости
внутри шара на разной глубине (параллакс), уровень жидкости. Не three.js, не SDF.
**Звук (новый):** стеклянная гармоника (трение по бокалам) и челеста синтезом + живые записи воды/стекла.
Язык — английский, без голоса, крупные титры. 720p.
