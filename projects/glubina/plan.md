# ГЛУБИНА — план (v1, 2026-11-23)
720×1280, 30 fps, 41,65 с, без голоса, текст на английском (пиксельный шрифт 5×7).
Стиль: пиксельный нуар, дизеринг Bayer 8×8; холодная палитра бездны / дневная палитра поверхности; янтарь — только свет приманки.

Звук: `audio/score.py` (свой синтез + CC0 sfx-kit: props-splash, pop-*, impact-*). Мастер — цепочка «без озвучки».
Превью: `node projects/glubina/tools/sheet.cjs out.png t1 t2…` (SCALE=.3).
