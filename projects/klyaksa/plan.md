# КЛЯКСА — тушь на свитке (полная воля, 720p, без голоса)
Сюжет: мастер рисует дракона без глаза → капля туши падает (хук) → клякса оживает → кисть гонится (удары, прятки среди точек мха, полёт со стаей птиц) →
у края бумаги мастер берёт воду (вода смывает тушь — показано на пятне) → клякса прыгает на кисть → кисть поднимает её к дракону → клякса прыгает в пустой глаз → дракон оживает, впитывает все кляксы, рычит, улетает кольцом вокруг солнца, подмигивает → «EVERY MASTERPIECE NEEDS ONE MISTAKE» + печать с кляксой.
Стиль (новый): тушь sumi-e, мазки щетинками с сухой кистью, бумага с волокнами, вода = линза-шейдер, размыв туши водой, золото с bloom, шёлковая монтировка свитка.
Звук (новый): кото и сякухати синтезом, тайко (запись CC0), реальные шлепки/капли/рык/гонг (CC0, assets/sfx/CREDITS.md).
## Карта
src/engine.js — E: холсты K (R тушь, G киноварь, B золото), X (R вода, G размыв, B маска «над бумагой»), шейдер, E.stroke/blob/erase/cache, E.K ключи
src/world.js — Wd: путь дракона (кольца→полёт→орбита), голова headTf/eyePos, облака, горы, водопад, сосна, мох MOSS, птицы, волны, камни, печать, marks+absorb
src/chars.js — C.blot (клякса), C.brush (кисть+рука+тень)
src/story.js — тайминг 48,2 с: brushAt, blotAt, camAt, dragonAt, капли, inkWipe 31.45–32.5, титр 45.2–46.8, печать 46.9
Рендер: node render.cjs render/klyaksa.mp4 (~5 мин); лист: node tools/sheet.cjs out.png t1 t2…; звук: python3 audio/sound.py
