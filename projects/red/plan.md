# «RED» — сериал, 3 серии (план v1, 2026-11-26)
Герой — Лео, родился дальтоником (не видит красный). Дед — художник. Весь сериал — глазами Лео (шейдер CVD),
короткие вспышки «как на самом деле» — сплит или мазок.
Смысл: «He couldn't give me red. So he taught me what it feels like.» → «Someone taught you how the world feels.
Tell them — while they can still hear you.»

## EP1 «WARM» (~56 с)
| t | план | текст |
|---|---|---|
| 0–2.4 | ХУК: сплит по горизонтали — сверху яблоко в руке ребёнка ярко-красное (YOU SEE), снизу бурое (I SEE), граница — мазок | I WAS BORN WITHOUT RED. |
| 2.4–6.5 | Класс: дети рисуют, Лео рисует маму; вспышка реальным цветом — лицо мамы зелёное; дети смеются | I PAINTED MOM GREEN. |
| 6.5–10 | Дождь, Лео идёт домой, мнёт рисунок | EVERYONE LAUGHED. |
| 10–14.5 | Мастерская деда: тёплая лампа, холсты; дед разглаживает рисунок, улыбается | GRANDPA DIDN'T. |
| 14.5–21 | Дед срывает этикетки с тюбиков и пишет новые кистью: SUN ON YOUR NECK, RIVER, GRASS AFTER RAIN, …на красном — WARM | HE RENAMED EVERY COLOR. |
| 21–27 | Ладонь Лео на горячей кружке — «THIS IS RED». На холодном стекле — «THIS IS BLUE» | |
| 27–33 | Лео рисует с закрытыми глазами, дед смотрит | I LEARNED TO PAINT WHAT THINGS FEEL LIKE. |
| 33–40 | Мазок-переход — годы; Лео 12 на выставке, закат; вспышка реальным цветом — картина верная; лента «1st» | I NEVER SAW MY PAINTINGS. BUT THEY WERE RIGHT. |
| 40–47 | Ночь, дед пишет — мазок мимо, трёт глаза, подносит холст к лицу | |
| 47–53 | Дед протягивает два тюбика без этикеток: «LEO… WHICH ONE IS WARM?» Лео не может различить | |
| 53–56 | Карточка RED · EP 1/3 · NEXT: HIS EYES | |

## EP2 «HIS EYES» (~55 с)
| t | план | текст |
|---|---|---|
| 0–2.4 | ХУК: глаз деда крупно, мутнеет | GRANDPA WAS GOING BLIND. |
| 2.4–7 | Дед у окна, холсты повёрнуты к стене, кисти в банке сухие | HE STOPPED PAINTING. |
| 7–14 | Сплит: что видит дед (цветные пятна без формы) / что видит Лео (форма без красного) | HE SAW COLOR. I SAW SHAPE. |
| 14–19 | Лео (16) ставит большой холст, вкладывает кисть в руку деда | TOGETHER — ONE PAIR OF EYES. |
| 19–30 | Монтаж: Лео ведёт руку деда по контуру, дед по этикеткам на ощупь (узелки на тюбиках) выбирает краску; сезоны за окном | |
| 30–37 | Холст закрыт тканью — дед не показывает: «IT'S FOR YOU. YOU'LL SEE IT ONE DAY.» | |
| 37–44 | Ночь: дед кладёт последний мазок, откидывается, улыбается: «DONE.» Лео спит на стуле | |
| 44–51 | Утро: кресло пустое, кисть на полу, солнечный луч | HE NEVER SAW IT. |
| 51–55 | Карточка EP 2/3 · NEXT: RED | |

## EP3 «RED» (~62 с)
| t | план | текст |
|---|---|---|
