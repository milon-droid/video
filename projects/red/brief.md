# Решения Claude (полная воля)
- Сериал «RED», 3 серии по ~50–60 с, 720×1280, 30 к/с, без голоса (смысл — надписи EN, как прошлые ролики).
- Стиль (новый): **живая масляная живопись** — анизотропный Кувахара по направлению мазка, импасто (рельеф краски
  под косым светом, блик на сырой краске), холст с переплетением, мазки «перекрашиваются» на двойках, переходы —
  мазок кисти размазывает один кадр в другой (как живопись на стекле).
- Фишка серии: весь мир показан **глазами героя-дальтоника** (шейдер дейтеранопии: красный = бурый/оливковый).
  Зритель сам не видит красного до финала 3-й серии — там цвет «прорастает» по экрану.
- Звук (новый): живые записи — фортепиано по нотам + виолончель, фоли живописи (кисть по холсту, мастихин,
  тюбик, ткань), дождь, класс, часы.
