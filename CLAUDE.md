# Видео-проекты: правила работы

Пользователь даёт ТЗ на видео, Claude собирает видео. Общение — на русском.

## Разделение ролей

**Claude делает сам:**
- монтаж, склейку, обрезку, переходы, тайминг (ffmpeg);
- базовую анимацию и моушн-графику: текст, титры, плашки, фигуры,
  движение/масштаб/поворот/прозрачность картинок, простые инфографики,
  Ken Burns по фото (HTML/CSS/JS → покадровый рендер через Playwright → ffmpeg,
  либо Python + Pillow);
- наложение звука/музыки, если файл предоставлен; субтитры.

**Claude НЕ генерирует сам, а запрашивает у пользователя:**
- изображения, требующие высокого качества (фото, иллюстрации, персонажи, фоны);
- сложную анимацию (персонажная, 3D, сложные эффекты и симуляции);
- голос/озвучку и музыку.

Если пользователь в ТЗ сказал, что анимация не нужна — не добавлять её.

## Как запрашивать ассеты

Когда для задачи нужен ассет, который Claude не делает сам:
1. Остановиться и не подставлять «заглушку» молча.
2. Написать пользователю запрос по шаблону (и сохранить его в
   `assets/requests/<проект>-<NN>.md`):

   ```
   Нужен ассет #NN для проекта <проект>
   Тип: изображение / анимация / звук
   Что изображено: ...
   Где используется: сцена N, 00:05–00:09
   Формат: PNG/JPG/MP4/MOV(с альфой)/WEBM, размер 1920×1080 (или другой),
           прозрачный фон: да/нет, длительность (для анимации): ...
   Стиль/референсы: ...
   Имя файла: <проект>-NN-<кратко>.png
   ```
3. Можно продолжать работу над остальными частями, оставив на месте ассета
   помеченную временную плашку «ASSET #NN», если пользователь не против.

Пользователь передаёт файлы одним из способов:
- прикрепляет в чат;
- кладёт в `assets/incoming/` в репозитории (через GitHub) и сообщает об этом.

Полученные файлы Claude переносит в `projects/<проект>/assets/`.

## Структура проекта

```
projects/<проект>/
  brief.md      — ТЗ пользователя и уточнения
  plan.md       — раскадровка: сцены, тайминг, какие ассеты нужны
  assets/       — исходники (картинки, видео, звук)
  src/          — код анимаций/сборки
  render/       — результат (в git не хранится)
```

## Порядок работы над ТЗ

1. Прочитать ТЗ, задать уточняющие вопросы только по тому, что реально
   влияет на результат (формат, длительность, стиль).
2. Составить `plan.md` с раскадровкой и списком нужных ассетов —
   сразу запросить у пользователя все ассеты, которые не делает Claude.
3. Сделать черновой рендер (низкое качество/с плашками) для согласования.
4. После правок — финальный рендер и отправка файла пользователю.

## Параметры по умолчанию (если в ТЗ не указано)

- 1920×1080, 30 fps, H.264 (yuv420p), AAC 192k, MP4.
- Вертикальное видео (Reels/Shorts/TikTok): 1080×1920.

## Окружение

Доступно: ffmpeg/ffprobe 6.x, Python 3 + Pillow + numpy, Node 22,
Playwright + Chromium (для рендера HTML-анимаций).
Контейнер временный — всё ценное коммитить и пушить.
