# Единый визуальный стиль

**Это одно знание для всех жанров.** Жанры в `refs/` — только оглавление, где искать пример.
Приём из научпопа (рентген, шкала, маскот) так же нужен в супергероике, хорроре или симуляторе.
Читать этот файл **перед каждой новой сценой**, вместе с `preferences.md` и `lessons.md`.

Откуда: 13 референсов (`refs/*/*/style.md`, листы `sheet.jpg`) + наши серии и их разборы
(`lessons.md`, `retro-2026-11-05.md`). Метка в скобках: **[реф]** — увидел у них, **[наше]** — уже умеем и проверено.

## 2. Глубина кадра (три слоя)
- Передний план размыт (трава, край стола, плечо), герой резкий, фон с дымкой — bogomol, kran-zombi [реф].
- Фон — градиент, а не заливка: светлее у источника света, темнее к краям.
- Боке и частицы — **только мягкие** (радиальный градиент), разного размера и яркости. Плоские кружки — запрет пользователя [наше]: `AK.puff`, `bokeh()` с мягким краем.
- Снег, пыль, искры — разные в каждой сцене (размер, скорость, плотность) [наше, ретро: «снег одинаковый везде»].

## 3. Персонажи
- **Глаза:** белок + зрачок + веко. Полуприкрытые веки — усталость/скепсис (chto-esli), широко открытые — шок (2009-bitkoin). Брови несут эмоцию [реф]. Точки вместо глаз — только на дальнем плане.
- **Живость (обязательно):** моргание `AK.blink`/`autoBlink`, дыхание `AK.breathe`, рот по голосу `AK.mouth` + `tools/mouth.py`, тень на полу [наше].
- **Руки:** из двух звеньев с локтем `AK.limb`, дотянуться до точки `AK.reach`/`armTo`, кисть `hand()`; предмет реально переходит в руку (`glassesInHand`) [наше]. Рукав сужается к запястью (нерешённое #16 ретро ҚУАТ).
- **Позы:** ясный силуэт — руки вверх, указывает, пожимает плечами, хватается за голову. Смена позы **за 2–3 кадра с перелётом** (`AK.overshoot`), а не плавное перетекание за секунду: так в 2009-bitkoin и gosha [реф].
- **Шаг:** фаза из пройденного пути, ноги не скользят [наше].
- **Удар/падение:** замах `AK.anticip` → удар `AK.impact` (сплющивание, стоп-кадр 2 кадра, тряска) → отскок `AK.drop` [наше].
- **Вторичное движение:** волосы, капюшон, шарф догоняют голову с задержкой (нерешённое #20 ретро ҚУАТ).
- **Предмет-персонаж / маскот:** если объясняем механизм — у механизма лицо и руки (мозг за пультом, яйцо со скрещёнными руками, акула с мимикой) [реф]. В супергероике: сила или батарея с характером.
- Герой (или его лицо, руки, реакция) в кадре **≥ 70% времени** ролика [реф: почти все планы с героем; ретро: кульминация не только через телефон].

## 4. Камера и крупности
- Ключевой объект 40–60% высоты кадра; в хуке — крупно с первого кадра [наше: selfcheck п.3, урок ҚУАТ].
- **Скачок крупности на акцентном слове** (общий → средний за 1 кадр) вместо медленного наплыва — gosha 1,3 с [реф].
- Медленный наезд 1,00 → 1,08 или панорама 40–80 px внутри плана — у нас уже есть (`cam`, `push`, `pan`) [наше].
- **Влёт объекта из глубины:** маленький → во весь кадр за 0,3–0,4 с, с замедлением в конце, затем смена эмоции (akuly, хук) [реф].
- Разнообразие: вид сверху (kran-zombi-2), перспектива улицы с толпой (kran-zombi-1), крупно глаза, деталь на весь кадр (ящик, телефон, флешка) [реф]. Повторы планов ловит `scene-audit.cjs` [наше].
- Тревога — лёгкая ручная камера `AK.handheld` [наше].

## 5. Склейки и переходы
- По умолчанию **жёсткая склейка**. Затемнение (`dip`) — только когда прошло время. Не ставить затемнение между планами одной сцены (в Счётчике с.1 — между рукой и телефоном, 10,5 с).
- Смаз-панорама `AK.cut('whip')` — смена места [реф bogomol, akuly; наше].
- Белая вспышка `AK.cut('flash')` — шок, удар, «падаем» [реф padenie; наше].
- **Смена режима мира** для невидимого: рентген (тёмный фон + светящиеся линии внутри тела), тепловизор с рамкой «REC», сепия/старая бумага для прошлого [реф bogomol, padenie]. В супергероике — так показывать силу внутри героя.
- Сплит-экран «до / после», «они / он» с галочками и крестиками [реф baba-lyuda, kashan].

## 6. Табло и графика (главный общий приём рефов)
- **Постоянное табло сверху**: 1–3 плашки с цифрами сюжета (заряд, деньги, дни, возраст, страх %). Плашка 90–140 px высотой, цифры 54–80 px — **вдвое крупнее нашего** `Hud` (плашка 58 px, текст 34 px).
- Цифра меняется **тиком** (быстрый пересчёт 0,3–0,5 с) + вспышка цветом (красный при потере, зелёный при росте) + маленький «−2%» / «+40 000» вылетает рядом [реф; наше: `flash` в Hud, ChargeFlow].
- Цифры сюжета — из одной функции (`BATTERY`, `storyClock`, `storyBalance`) [наше].
- Ярлык на предмете: плашка-бирка с короткой линией к предмету («СТАРЫЙ СИСТЕМНИК») [реф].
- Штамп под углом 5–10° с ударом (`AK.impact`): «ВСЁ СГОРИТ», «ЗАЛОГ» [реф].
- Галочки и пункты списка выходят **по очереди** через 0,1–0,12 с, кнопка зеленеет [реф 2009-bitkoin].
- Большая цифра на полкадра (180–260 px) на главном факте; количество — сеткой иконок-человечков, которая заполняется рядами [реф akuly].
- Карточка героя как в игре (класс, уровень, сила, выносливость полосками) — знакомство за 5 с [реф baba-lyuda].
- Варианты выбора кнопками A/Б/В/Г с курсором; опрос зрителей «81% / 19%»; полароид с подписью [реф].
- Уже есть у нас: `GroupChat`, `CityGrid`, `RuleCard`, `TopDownMap`, `DashcamFrame`, `PhoneScreen`, `PowerDown`, `ChargeFlow`, `PartSticker`, `EndCard`.

## 7. Субтитры
- **Сериалы:** `KineticCaption` [наше] = как у рефов: 1–2 строки, капслок, сказанные слова белые, ещё не сказанные серые, ключевое жёлтым. Так и оставить.
- **Быстрые ролики ≤ 45 с:** одно слово 100–130 px, комикс-гротеск с толстой обводкой [реф bogomol, akuly, padenie].
- Подложку-плашку не ставить по умолчанию: обводка + тень + затемнение низа кадра градиентом (y 1100–1920, до 35%). Плашку включать только на светлом пятне (≥ 18% светлых точек) [наше: правило ҚУАТ].
- Субтитр не налезает на лицо, руки, телефон, табло [наше].

## 8. Движение элементов (кривые)
Из `html-animation` («Как движется: 4 правила») и `anim-kit`:
- вход/уход — сильное замедление (`power4.out`, в canvas `1-(1-p)**5`), 0,3–0,6 с;
- спокойное появление с 0,94 размера; «выстрел» — из 0 с перелётом `AK.overshoot`;
- по очереди 0,05–0,12 с;
- уходит тем же путём, что пришёл;
- колёса крутятся `AK.wheel`, дым клубами `AK.smoke`, пыль от удара `AK.dust` [наше].

## 9. Ритм и хук
- Новое событие (крупность, жест, плашка, цифра, звук) каждые 1–2 с; план 2,5–4 с; одна композиция ≤ 5 с [реф средний план 2,5–6 с; наше selfcheck п.4].
- Хук: к 0,5 с — герой или объект крупно и действие; к 1,5 с — правило/угроза одной фразой (место + герой + угроза) [реф kran-zombi, derevnya; наше].
- Финал: титр-крючок 3–4 слова, одно слово красным + анонс следующей серии одной фразой; чёрный кадр ≤ 0,5 с [реф kran-zombi-2, baba-lyuda; наше].

## Чек-лист стиля перед сдачей (дополняет selfcheck.md)
1. Яркость ≥ 0,25 (ночь ≥ 0,18), чёрного ≤ 35% (ночь ≤ 50%); у ночного плана есть цветной источник света.
2. Три слоя глубины; боке и частицы мягкие.
3. Герой в кадре ≥ 70% времени; глаза с веками, моргает, дышит, рот по голосу.
4. Позы сменяются с перелётом за 2–3 кадра; у ударов замах и отдача.
5. Событие каждые 1–2 с, композиция ≤ 5 с, хук крупно к 0,5 с.
6. Табло читается с телефона (цифры ≥ 54 px), цифры тикают и вспыхивают.
7. Затемнений между планами одной сцены нет.
8. Хотя бы один приём из п.5–6, которого не было в прошлой серии (смена режима, сплит, карточка, штамп, сетка иконок).
