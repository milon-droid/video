## Пользователь и процесс
- Сценарий пишет пользователь (в приложении Claude); здесь — сверка с `projects/<проект>/canon.md` → «несостыковки / идеи» → после «ок» сборка. `canon.md` обновлять после серии.
- Порядок: идея + сценарий → обсуждение → раскадровка → производство. Раскадровка пользователя главнее ТЗ. При «полной воле / сам делай» — не ждать «ок», сдавать 720p.
- Картинки высокого качества — промпты по пунктам, пользователь генерирует. Фото/PNG — только реф: персонажа рисовать кодом из подвижных частей, не клеить куски фото.
- Площадки TikTok и Reels. Не рендерить без просьбы; правка — только испорченный кусок или только звук. Превью — 720p ~10 МБ.
- Сам находить ошибки и предлагать решения. Помощников не запускать без «да». Всё важное — в файлы и коммит сразу.
- **Реестр требований:** каждое требование — строкой в `projects/<проект>/epN-trebovaniya.md` (дословно, статус, секунда); перед рендером проверять весь.
- **Новый ролик = новый стиль, движок, звук и сюжет.** Прошлые стили — `styles.md`, не повторять без просьбы. Стиль называть настоящим термином.
- Направления «развивать»: ХОЛОД, STITCHED, CROOKED, ТЕНЬ (романтика, хэппи-энд, без «заговора теней», на английском, мат у тени), SMILE-стиль (для комедии/сказки, не для хоррора), хочет японское, 3D. Идеи — «Чёрное зеркало». Рефы пользователя адаптируем (подход DAY 214).

## Хук и сюжет (главная слабость — хук, разбор 2026-11-26: `review-2026-11-26.md`)
- Красивый кадр/стиль — не хук. Рабочий хук: сразу герой + конфликт/вопрос в 1–2 с. Тест «пролистну ли на 2-й секунде?».
- Сюжет: начало-конец-хронология, 2+ поворота, препятствия, больше персонажей, хронометраж под идею. Красивая анимация без сюжета = «пролистнуть».
- Логика поступков: герой не вредит себе без причины, не находит правду сразу. Причина → следствие в кадре. Правило мира — сначала объявить, потом нарушить.
- Загадку не выдавать картинкой раньше времени; давление нарастает, второй поворот.
- Конечная мысль — не банальная, не опровергаемая, лучше от предмета истории (сердце в аппарате, песочные часы). Позитивный финал — позитивная музыка.
- Хоррор: страх в картинке (темнота, силуэт, частичный показ, глаза в темноте), не мультяшность. Скример — внезапный: ложный конец → лицо на 0,5 с + перегруженный крик → обрыв; без медленного превращения. «В хорроре главное — звук».
- Короткий ролик ≤ 45 с: событие каждые 1–2 с. Серия 1:30–2:00: планы 3–6 с. Петля: шов ≈3 с плавный, смысловой крючок (загадка → отгадка).
- Все счётчики/время/табло — из одной функции, совпадают между планами и сериями. Обещанное в реплике выполнять в кадре.
- «Контент внутри ролика» не повторять; жанры — не бренды. Остановка времени ради эффекта — не нравится.

## Кадр и анимация
- Не нравится: «плоско» одним планом, деревянная анимация, плоские кружки пыли, «куклы» без моргания, непонятные фигуры. Нравится: живописные фоны, свет за героем, разные планы, неон.
- Живость: лицо из частей (брови/рот/зрачки), инерция и сжатие-растяжение, ключи с замахом и перелётом; 2–3 действия на план; моргание, дыхание, рот по голосу; шаг без скольжения.
- Реализм мира: реальный масштаб, массовка, процедуры как в жизни, логичная география; голова по пропорциям тела, не вращать > 20°.
- Лица и действие выше y 1100 (субтитры 1150–1400); текст в x 60–920; **текст не вылезает за плашку** — мерить и вписывать (поля ≥ 8%), не закрывать персонажей.
- Яркость ≥ 0,25 (ночь ≥ 0,18); три слоя глубины; композиция ≤ 5 с с движением камеры; герой в кадре ≥ 70%.
- Ключевой предмет — поверх фигуры и прослежен через все планы. Звёзды — фигурами (☆ рисуется закрашенным).
- Перед раскадровкой — раздел 11 `visual-style.md`, взять ≥ 2 новых приёма. Перед сдачей — `selfcheck.md` целиком.

## Звук
- Каждое событие — свой звук; звукоподражание текстом не заменяет SFX (чих — запись). Звуки пользователю почти везде нравятся.
- Голос громче фона ≈10 дБ (`vo-balance.py`), телефон — `sfx-phone.py`. Мастер −14 LUFS, пик ≤ −1 dBTP (`master.py`). Без голоса — компрессор + loudnorm + лимитер (`lessons.md`).
- Хвост атмосферы до последнего кадра. ТЗ «только CC0» — без Oculus. Живые записи — скилл `free-audio`.

## Голос
- По умолчанию видео **без озвучки** (2026-11-15), пока пользователь не попросит. Русский синтез для живого героя — «робот»; английский Qwen VoiceDesign — ок; в «ПОПАЛ» русский Qwen понравился.
- Ударения: `--check` до синтеза, `vo-stress-check.py` после. Догонные реплики — клон с удачной реплики героя. Синтез ≈ 5–6 с на 1 с речи — в это время не рендерить.
- Меняя реплику — менять субтитры и привязки. Субтитры — читаемые: печатный шрифт, крупно, подсветка полосы.

## Remotion
- Время плана = max(минимум, реплики + 0,15 с) из `durations.json`. Превью `node scripts/still.mjs` (`SCALE=.4`). 720p — отдельная композиция. В однострочном коде — только `/* */`.
