# Стили прошлых роликов (не повторять без просьбы) — каталог с путями к движкам

Перенесено из `digest.md` 2026-11-27. Читать при выборе стиля нового ролика.

- Уже были стили (не повторять без просьбы): flat 2D Remotion (Счётчик/ПОПАЛ), аниме (ОДИНОЧКА), three.js-пластилин (Тень), **ризограф-печать + бесконечный зум Droste (КОРОБКА: `projects/korobka/src/riso.js` — 3 краски в каналах RGB холста → шейдер печати)**, **GLSL SDF-рейтрейсинг: жидкие капли с глазами в лава-лампе, стекло, DOF/bloom (ЛАВА: `projects/lava/src/shader.js`)**, **векторный люминофор / луч осциллографа: всё одной светящейся линией, морфинг линии, рукописный Hershey (ЛИНИЯ: `projects/liniya/src/engine.js`)**, **бумажная диорама с подсветкой: слои бумаги с фактурой, тени по глубине, параллакс, DOF, светлячки-bloom, куклы с IK рук (МАЯК: `projects/mayak/src/engine.js`, `chars.js`)**, **тушь sumi-e на свитке: мазки щетинками с сухой кистью, бумага с волокнами, вода-линза и размыв туши шейдером, золото-bloom (КЛЯКСА: `projects/klyaksa/src/engine.js`)**, **песочная анимация на световом столе: плотность песка в canvas → шейдер просвечивания лампой, зёрна в мировых координатах, переходы «ладонь сметает», текст пальцем Hershey (LATER: `projects/pesok/src/engine.js`)**, **пиксельный нуар с дизерингом Bayer: буфер 240×427 (R=яркость, G=янтарь) → палитра 5+3 тонов, пиксель ×3, свой шрифт 5×7, кадр над/под водой (ГЛУБИНА: `projects/glubina/src/px.js`)**.
- Стиль **живая гравюра укиё-э + кабуки (20 WINTERS, 2026-11-24)**: 9 «досок»-красок в каналах RGB трёх холстов → шейдер печати (васи, волокна доски, барэн, приводка, печать по доскам как переход, разрез гравюры мечом), тени на сёдзи, грим кумадори, ми-э под цукэ; звук — живые записи сямисэна по нотам + цукэ/хёсиги/тайко (`projects/fuyu/src/engine.js`, `audio/score.py`). Свет в ночи = «отсутствие краски» (радиальный градиент тёмной краски), а не жёлтая поверх синей (даёт зелень).
- Стиль **«вспышка в темноте» (12 SHOTS, 2026-11-23)**: three.js, мир виден только во вспышке (прожектор у объектива с тенями), кадр вспышки держится и гаснет, след на сетчатке, дата на кадре; существо — чёрная «пустота» с глазами-отражателями (`projects/vspyshka/`). Урок: процедурное 3D-существо вблизи = «манекен»; страшно — силуэт, частичный показ, темнота, глаза в темноте.
- Стиль **живой витраж (PIECES, 2026-11-26)**: куски стекла в свинце в холстах G/M/T → шейдер просвечивания светом сзади (небо/солнце/лампа), фактура, преломление, ореол; лица гризайлем; переход — экран бьётся 3D-осколками (снимок сцены на треугольниках, `textureLod 0` — иначе чёрные осколки из пустых mip); сборка витража летящими кусками (`E.ASM`); собор — проекция витража на пол и лучи (`projects/vitrazh/src/engine.js`). Мозаика с `ky<1`: число рядов делить на `ky`, иначе снизу дыра.
- Стиль **живая вышивка (STITCHED, 2026-11-26)**: мир из ниток на льне — холсты-данные (цвет / тип+высота / локальные координаты узора через CanvasPattern, чтобы стежки ехали с объектом) → шейдер нитей (гладь, татами, узелки, одна нить, лён, рельеф, анизотропный блеск); вещи прошиваются рядами с иголкой; снаружи пялец — настоящая размытая студия + интерфейс LIVE (`projects/stitched/src/engine.js`). Звук — живые записи швейной машинки/вышивки (Freesound CC0) + шкатулка синтезом.
- Стиль **живой рельеф «пряник и глазурь» (CROOKED, новогодний, 2026-11-26)**: карта высот в холсте H (R высота, G искры сахара, B глянец) + материал/свечение/глубина в M → шейдер барельефа: нормали, самозатенение лучом по высотам, глянец, подповерхностный свет воска/кожи, DOF-боке и перевод фокуса; текст выдавлен глазурью (Hershey трубкой); звук — музыкальная шкатулка синтезом + пиццикато Карплус-Стронг + живые записи (`projects/pryanik/src/engine.js`). Объединение капсул — трубками с `lighten` (обводка пути с `darken` даёт швы на внутренних границах); 8-бит высоты: число колец трубки ∝ пикселям, HS × zoom.
- Стиль **«проклятый мультфильм 1932» (SMILE, 2026-11-23)**: ч/б плёнка шейдером (зерно, пыль, волоски, царапины, мерцание, дрожание, ореол, гейт, прожиг) + персонажи «резиновых шлангов» (глаза-пирожки, перчатки, шланги), анимация на двойках, всё пружинит в такт своего регтайма; хоррор — ломка весёлого (`projects/ulybka/src/`). Новый ролик просит **новый сюжет**, не только стиль («другой сценарий, я же сказал что новое хочу»).
- Стиль **тепловизор FLIR (ХОЛОД, хоррор, 2026-11-23)**: three.js рендерит не цвет, а °C во float-цель; шейдер камеры — ironbow/white-hot, изотерма бирюзой, ореолы, шум матрицы, NUC-замирание; HUD с настоящими замерами `readT`; зеркало/стекло — Reflector в градусах (`projects/holod/src/core.js`). Вертикаль 9:16 даёт узкий горизонтальный угол (±16° при fov 54): собака/люди читаются только в профиль или 3/4 на 2–3 м, не сверху вплотную.
- Стиль **«живая масляная живопись» + глаза дальтоника (RED, сериал, 2026-11-26)**: 2D-сцена → анизотропный Кувахара (½ разрешения, детали — отдельно по маске) → мазки-дэбы в мировых координатах (эллипс вдоль потока, щетина, цвет из центра мазка, перекраска 6 р/с) → импасто-свет, холст; весь мир через дейтеранопию (Machado), маска «правда» показывает настоящий цвет (сплит, вспышки) (`projects/red/src/paint.js`). Звук — живое фортепиано по нотам из одной записи C4 + группа виолончелей, фоли кисти. Скорость ≈1,4 с/кадр.
- **Стиль «живой скетчбук» (DAY 214, 2026-11-23):** карандаш с кипящими линиями (3 прохода: линия/эхо/строительная) + акварель шейдером (тёмные края через mip-размытие, грануляция, сдвиг от линий), бумага, перелистывание страниц, рисование «само» (`E.rv` — по номеру штриха), ластик стирает графит. `projects/skvoz/src/engine.js`. Цвет = связь героев.
- Стиль **макросъёмка снежного шара (SNOW GLOBE, зима, 2026-11-27)**: свой WebGL2-движок оптики — луч × сфера, френель стекла, преломление по Снеллю в жидкость (n 1,33; выше уровня — воздух, уровень воды двигается), полное внутреннее отражение, выход с хроматической аберрацией, фон за шаром — плоскость ⟂ взгляду (переворачивается линзой шара, как в жизни); мир внутри — 3 расписные плоскости «смола с лаком» на разной глубине с окнами по пирамиде камеры (камера может быть внутри шара), снег — детерминированные частицы в вязкой жидкости от событий тряски, блёстки; 2-й проход — блум из mip, ACES, зерно (`projects/globus/src/engine.js`). Звук — стеклянная гармоника + челеста синтезом, записи воды/стекла CC0 (`audio/score.py`). Урок: камера под водой, глядя вверх, видит перевёрнутое отражение поверхности (ПВО) — ставить камеру над водой.
