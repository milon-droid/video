# База знаний проекта

Растёт после каждого ролика (скилл `after-video`). Читать перед каждым новым ТЗ.

| Файл | Что внутри |
|------|-----------|
| `preferences.md` | вкус и требования пользователя: стиль, цвета, шрифты, тон, что нравится/не нравится |
| `lessons.md` | что сработало, ошибки и как их избежать, технические грабли |
| `visual-style.md` | **единый визуальный стиль** для всех жанров: свет, глубина, персонажи, камера, склейки, табло, субтитры, ритм; чек-лист стиля и «было → станет» |
| `log.md` | журнал всех роликов: дата, тема, длительность, что нового появилось |
| `toolbox.md` | установленные скиллы/плагины/агенты: откуда, зачем, проверены ли |
| `../templates/components/` | готовые куски сцен (титры, плашки, переходы), вынесенные из проектов |
