# «Хватит бояться акул»

Жанр: **научпоп, разрушение мифа** · Метки: интерфейс, персонажи, текст, хук · Язык: рус.
Длительность 68 с · склеек 11, средний план 6.16 с · громкость -13.8 LUFS · речь ≈ 2.9 слова/с
Листы: `sheet.jpg`, `hook.jpg` · цифры: `report.md`

**О чём:** акулы не людоеды; цифры укусов, виды, древность акул; бояться стоит мира без них.

**Хук (0–3 с):** акула плывёт из глубины в упор, рычит с зубами — и тут же становится милой, подмигивает. Шкала «СТРАХ ПЕРЕД АКУЛАМИ 100%» сверху.

**Картинка и анимация:** мультяшный флэт, морские градиенты, лучи света в воде; одна «маскот»-акула меняет эмоции (злая, милая, фу, плачет).

**Текст на экране:** HUD-шкала страха падает 100% → 92 → … → 3%, и цифра — сюжет ролика; одно слово крупно комикс-шрифтом; большие цифры «2 000–6 000», «200», «12 м», «400 лет»; столбики сравнения «акулы 10 / молнии 6000».

**Структура и концовка:** миф → факты по одному, каждый снижает шкалу → неожиданная сторона (акулы древнее динозавров) → вывод-перевёртыш.

**Берём себе:**
- шкала, которая падает с каждым фактом — сквозная драматургия научпопа
- один персонаж-маскот, который реагирует мимикой на каждый факт
- сравнение столбиками с абсурдным контрастом
