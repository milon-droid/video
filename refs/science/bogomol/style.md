# «Вам всю жизнь врали про богомола»

Жанр: **научпоп, разрушение мифа** · Метки: текст, переходы, эффекты, хук, ритм · Язык: рус.
Длительность 39 с · склеек 13, средний план 3.01 с · громкость -10.9 LUFS · речь ≈ 2.9 слова/с
Листы: `sheet.jpg`, `hook.jpg` · цифры: `report.md`

**О чём:** самка богомола не всегда откусывает голову самцу — миф из лабораторных опытов.

**Хук (0–3 с):** «Вам всю жизнь врали» + морда богомола в упор, на слове «врали» — разбитое сердце. Картинка меняется каждые 0,5–0,75 с.

**Картинка и анимация:** мультяшный флэт с глубиной (размытый передний план травы, боке), смена «миров»: старая книга/архив в сепии, лаборатория, «рентген» на тёмно-синем со светящимися нервами. Быстрый монтаж 3 с и резкие смазы.

**Текст на экране:** одно слово за раз крупным комикс-шрифтом с обводкой, ключевые — жёлтым; под словом мелкий логотип канала; большие цифры «17%», «80%», значок «СТОП», спидометр.

**Структура и концовка:** миф → откуда взялся → правда с цифрой → как выживают самцы → «цинизм эволюции» (рентген) → шутливый финал.

**Берём себе:**
- «рентген»: тёмный фон + светящиеся линии внутри персонажа для объяснения механизма
- сепия/старая бумага для «прошлого»
- одно слово крупно — темп 3 слова/с, подходит для коротких ≤40 с
