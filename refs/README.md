# Библиотека референсов

Пользователь присылает ролики-примеры в чат; Claude разбирает каждый и раскладывает
по **жанрам** (папки) и **приёмам** (метки в таблице). Перед новым ТЗ — смотреть
сюда: нужный жанр + метки приёмов.

## Как добавлять
1. Файл от пользователя (чат или `assets/incoming/`). Ссылки TikTok/Reels/Shorts из
   облака обычно не скачиваются — просить файл (сохранить или записать экран).
2. `python3 tools/ref.py <файл> -o refs/<жанр>/<имя>` → report.md, shots-N.png, hook.png.
3. Рядом `style.md` — паспорт стиля (хук, ритм, анимация, текст, звук, что берём / что нет;
   шаблон — скилл `reference-research`).
4. Строка в каталог ниже. Исходные видео в git не храним (`.gitignore`); файлы пачки
   2026-11-07 остались в истории git (коммиты «Add files via upload», 250ae24 и раньше) —
   при нужде достать `git show <коммит>:assets/incoming/<файл>`. Имя файла — в report.md.

## Метки приёмов
`персонажи` — анимация героев по частям, мимика, рот · `камера` — наезды, панорамы, тряска ·
`переходы` — склейки, вайпы, маски · `текст` — субтитры, кинетическая типографика ·
`интерфейс` — телефон, чаты, HUD · `эффекты` — свет, частицы, сила, молнии ·
`звук` — музыка, удары, голос · `хук` — первые 1–2 с · `ритм` — длина планов, темп

## Что общего по жанрам (пачка 2026-11-07, 13 роликов)
- **Все 13 — плоский вектор с голосом рассказчика**, как наши сериалы. Средний план 2,5–6 с,
  речь 2–3,4 слова/с, громкость −10…−22 LUFS (у нас −14 — нормально).
- **Почти везде сверху есть постоянный «экран игры»**: счётчики, шкала, рубрика. Цифры меняются
  по сюжету, и зритель видит прогресс без слов. Это главный общий приём пачки.
- **sim/** — хук = правило игры в первую фразу («ты… условие… не успел — …»), HUD-ресурсы,
  выбор вариантов, финал-вопрос «да или нет?» / «часть 2». Ролики длинные (1–4 мин).
- **science/** — короче (39–69 с), быстрее (средний план ~3 с), **одно крупное слово** комикс-шрифтом
  с жёлтыми ключевыми, мелкий логотип под ним; «смена мира» для невидимого (рентген, тепловизор, сепия);
  маскот с мимикой; финал — шутка или «а ты как думал? пиши в комментах».
- **comedy/** — один узнаваемый герой, рубрики-главы, сравнение сплит-экраном, анонс серии.
- **horror/** (триллер-сериал) — герой + место + угроза в первой фразе, ресурсы иконками,
  ночь почти чёрная, обрыв на звуке и титр «День 1 / продолжение следует».

## Для текущих сериалов (ҚУАТ, Тыныс, Счётчик) — что взять в первую очередь
1. RPG-карточка героя в серии 1 (baba-lyuda) — знакомство за 5 с.
2. Счётчик, который меняется по сюжету, всегда на виду (derevnya, chto-esli, akuly) — в «ҚУАТ» уже есть батарея; добавить второй (деньги / время).
3. Инвентарь с иконками и цифрами (kran-zombi-1).
4. Сплит-экран сравнения с галочками/крестиками (baba-lyuda, kashan-uilenesin).
5. «Смена мира» для силы героя — рентген/тепловизор вместо обычного кадра (bogomol, padenie-s-krovati).
6. Финал: титр-крючок 3–4 слова + анонс следующей серии одной фразой (kran-zombi-2, baba-lyuda).
