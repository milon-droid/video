# Библиотека референсов

Пользователь присылает ролики-примеры в чат; Claude разбирает каждый и раскладывает
по **жанрам** (папки) и **приёмам** (метки в таблице). Перед новым ТЗ — смотреть
сюда: нужный жанр + метки приёмов.

## Как добавлять
1. Файл от пользователя (чат или `assets/incoming/`). Ссылки TikTok/Reels/Shorts из
   облака обычно не скачиваются — просить файл (сохранить или записать экран).
2. `python3 tools/ref.py <файл> -o refs/<жанр>/<имя>` → report.md, shots-N.png, hook.png.
3. Рядом `style.md` — паспорт стиля (хук, ритм, анимация, текст, звук, что берём / что нет;
   шаблон — скилл `reference-research`).
4. Строка в каталог ниже. Исходные видео в git не храним (`.gitignore`).

## Метки приёмов
`персонажи` — анимация героев по частям, мимика, рот · `камера` — наезды, панорамы, тряска ·
`переходы` — склейки, вайпы, маски · `текст` — субтитры, кинетическая типографика ·
`интерфейс` — телефон, чаты, HUD · `эффекты` — свет, частицы, сила, молнии ·
`звук` — музыка, удары, голос · `хук` — первые 1–2 с · `ритм` — длина планов, темп
