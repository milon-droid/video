# «Что, если бы ты проснулся семилетним и помнил всё?»

Жанр: **симулятор «что если» (ты-история)** · Метки: интерфейс, хук, персонажи, ритм · Язык: рус.
Длительность 72 с · склеек 13, средний план 5.51 с · громкость -14.8 LUFS · речь ≈ 2.3 слова/с
Листы: `sheet.jpg`, `hook.jpg` · цифры: `report.md`

**О чём:** прожить жизнь заново, ничего не меняя: школа, аул, первая любовь, общага, собака, свадьба, дочь — и вопрос «рискнул бы изменить?».

**Хук (0–3 с):** вопрос «Что, если…?» крупным шрифтом + лицо спящего героя крупно; через 3 с HUD «Возраст 7 / Мозг 30».

**Картинка и анимация:** плоский вектор с мягкими градиентами и шумом, тёплые закаты, сменяется палитра под каждый возраст. Один герой в разных возрастах, ровные планы по 5–6 с без суеты.

**Текст на экране:** HUD сверху справа «ВОЗРАСТ / МОЗГ / ПОПЫТКА №1», цифры растут; субтитры 1–2 слова внизу, жёлтое ключевое слово; полароид с подписью «я, 7 лет» в финале.

**Структура и концовка:** хронология жизни с ускорением; эмоциональная пауза (собака стареет) → «двадцать восемь… раз… три» → «Часть 2 — меняешь всё. Ты бы рискнул? Да или нет?».

**Берём себе:**
- HUD «возраст / мозг» — два числа, которые расходятся, и есть вся идея
- смена палитры = смена времени (утро детства, закат юности, дождь взрослой жизни)
- финальный вопрос с выбором «да или нет?» — повод для комментариев
