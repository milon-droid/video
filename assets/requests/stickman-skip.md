# Ассеты для stickman-skip v4

Общие правила для всех картинок:
- Прикладывать к генерации один из фонов (bg0) как референс стиля.
- Предметы: прозрачный фон (PNG). Если генератор не умеет прозрачность — однотонный ярко-зелёный #00FF00.
- Светящиеся (неоновые) элементы: чисто чёрный фон #000000 — Claude наложит их режимом «свечение».
- Один предмет = одна картинка, предмет целиком в кадре, с запасом по краям.
