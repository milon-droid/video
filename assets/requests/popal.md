# Запрос ассетов — «ПОПАЛ» (все необязательные)

Картинки, персонажей, фоны и анимацию Claude рисует сам кодом (плоский вектор, Remotion).
Без этих файлов будет черновой синтез-голос (Piper) и своя музыка (`tools/music.py`).

Ассет #01 для проекта popal
Тип: звук (голос)
Что: озвучка серии 1 по репликам из projects/popal/plan.md, раздел 6 (Витя/ЗК, Баба Яга, Кощей, водитель, лягушка).
Где используется: вся серия 1, 00:00–01:21
Формат: WAV или MP3, по одной реплике на файл (или одна дорожка с паузами 1 с между репликами), без музыки и шумов.
Стиль: Витя — уставший молодой парень, ироничный; Яга — прокуренная тётка из окошка; Кощей — тихо, низко, вежливо-жутко.
Имя файла: popal-01-<номер плана>-<кто>.wav (например popal-01-08-yaga.wav)

Ассет #02 для проекта popal
Тип: звук (музыка)
Что: тема сериала — сказочно-эпичная (балалайка/гусли/хор + бит), можно с тихим началом и «эпичным» подъёмом.
Где используется: под всей серией, тихо под голосом.
Формат: WAV/MP3, 80–90 с, свободная лицензия или ваша.
Имя файла: popal-02-theme.mp3
